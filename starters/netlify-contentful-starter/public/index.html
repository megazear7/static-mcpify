⚡ static-mcpify Contentful starter

This starter ships with sample Contentful-shaped content and can rebuild from your own Contentful space.

MCP endpoint: /mcp

{
  "static-mcpify-contentful": {
    "type": "http",
    "url": "https://your-site.netlify.app/mcp"
  }
}

Add CONTENTFUL_API_TOKEN and SPACE_ID in Netlify to rebuild on deploy. Until then, the bundled sample content is served immediately.
