# static-mcpify Netlify static starter

Deploy a ready-to-use MCP server backed by bundled filesystem content.

## What you get

- Preloaded sample Markdown and JSON content in `content/`
- A Netlify Function already wired to `/mcp`
- `netlify.toml` with the correct redirect and function bundling config
- A tiny landing page in `public/`

## Deploy

Use the Netlify button from the main project docs, or deploy this starter directory as the site base.

## Local notes

Edit the content files, redeploy, and point your MCP client at `/mcp`.
