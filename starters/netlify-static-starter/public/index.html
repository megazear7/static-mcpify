⚡ static-mcpify static starter

This starter deploys a ready-to-use MCP server from bundled filesystem content.

MCP endpoint: /mcp

{
  "static-mcpify-starter": {
    "type": "http",
    "url": "https://your-site.netlify.app/mcp"
  }
}

Content is preloaded under content/. Edit Markdown or JSON files and redeploy.
