About the project

static-mcpify helps teams publish content to MCP without runtime complexity.

What it is

A TypeScript-first npm package and CLI that builds static content artifacts and serves them as MCP tools.

Design principles

  • Static outputs for reliability and speed
  • Descriptive configuration + schema validation
  • Simple deploy paths for serverless and Node

Use-case highlights

Product docs AI assistant

Keep docs in CMS, ship static MCP tools for support copilots.

Customer onboarding portals

Expose playbooks, tutorials, and FAQ content as reliable tools.

Internal engineering knowledge

Package architecture docs and standards for team-wide AI access.
