Deploy static-mcpify on Netlify

Use Netlify for the static brand site and serverless MCP endpoints.

Deployment flow

1
Connect repository

Use the Netlify GitHub integration to link your repo.

2
Set build command

npm run build:ts && npm run build:contentful

3
Publish directory

netlify/brand

4
Configure functions

Point [functions] directory at netlify/functions.

5
Add secrets

Define CONTENTFUL_API_TOKEN and SPACE_ID in Netlify environment variables.

Reference netlify.toml

[build]
publish = "netlify/brand"
command = "node --version && npm --version && npm run build:ts && npm run build:contentful"

[functions]
directory = "netlify/functions"
node_bundler = "nft"

Endpoint checklist

GET health check

Return {"status":"ok"} to verify function health quickly.

POST MCP JSON-RPC

Accept MCP requests at paths like /example/static/mcp and /example/contentful/mcp.

This site is fully static and Netlify-ready: HTML + CSS in netlify/brand with no client build step required.
