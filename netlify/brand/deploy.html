What each starter includes

1
Sample content

Each starter ships with preloaded content so the first deploy exposes working MCP tools immediately.

2
Auto-wired endpoint

Both starters publish a Netlify Function at /mcp with JSON health responses for GET requests.

3
Included config

Every starter includes its own package.json, netlify.toml, landing page, and content files.

4
Contentful-ready option

The Contentful starter keeps the first deploy functional even before you add CONTENTFUL_API_TOKEN and SPACE_ID.

Reference netlify.toml

[build]
publish = "public"
command = "npm run build"

[functions]
directory = "netlify/functions"
node_bundler = "nft"

[[redirects]]
from = "/mcp"
to = "/.netlify/functions/mcp"
status = 200

Endpoint checklist

GET health check

Return {"status":"ok","server":"..."} so you can verify function health quickly after deploy.

POST MCP JSON-RPC

Accept MCP requests at /mcp so clients can connect without extra routing setup.

Both starters live in templates/ and are designed to be deployed as independent Netlify base directories from this repository.
