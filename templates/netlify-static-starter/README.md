# static-mcpify Netlify static starter

This starter deploys a ready-to-use MCP server backed by checked-in filesystem content.

## What you get

- A Netlify Function at `/mcp`
- Sample static content in `content/`
- A lightweight landing page in `public/`
- Zero CMS setup required

## Local changes

Edit the files in `content/entries/**` to replace the sample guides with your own content.
